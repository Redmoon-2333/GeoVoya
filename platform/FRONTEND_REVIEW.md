# 天目·寻境 · 前端交流版

用于与地理组逐页讨论课程、材料和交互。分支：`ui/geography-review`。沿用 Vue 3、TypeScript、Pinia、Vue Router 和 Lucide，不引入新运行依赖。

## 本机演示

从 `platform/frontend/` 启动前端即可，不需要启动 Python 服务：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开前端实际输出的地址并加上 `/?demo=1`，例如 `http://127.0.0.1:5173/?demo=1`。页面标明“前端演示 · 浏览器保存”。演示从空档案开始，学习记录由体验者自己创建，不预置学生表现或教师评分。

前端依赖安装完成后，也可直接启动：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5175 --strictPort
```

首次使用需准备本地素材。此工作分支继续排除原始照片及派生预览，不把团队素材上传到 GitHub：

```powershell
$env:GEOVR_PHOTO_DIR = 'D:\桌面\VR\天目山柳杉照片-2026\天目山照片-202608\普通照片-ziyao'
$env:GEOVR_PANORAMA_DIR = 'D:\桌面\VR\天目山柳杉照片-2026\天目山全景图片-202608\CAM_001'
node ../tools/prepare-assets.mjs
```

其他电脑需替换为当地经授权的素材路径。普通照片沿用根 README 中的三个文件；全景使用 `CAM_20260818103558_0030_D.JPG`、`CAM_20260818103703_0032_D.JPG`、`CAM_20260818103812_0034_D.JPG`。脚本校验全景 2:1 尺寸，生成 4096 像素宽的预览，原图保持不变。缺少全景时可继续体验其他模块，播放器提供错误与恢复入口。

## 建议讨论顺序

1. **项目总览**：查看共同考察和四专题入口，确认高中地理课堂的内容顺序。
2. **数字沙盘 / 山地剖面**：点选海拔带，隐藏或显示参考名称，记录带谱笔记；用上下按钮重排四带、提交检查，再去学习反馈看过程记录。
3. **360° 全景**：鼠标或触摸拖动、滚轮或按钮缩放、键盘方向键环视、切换三份真实影像。来源面板显示原文件名。素材编号不代表路线，草记与普通照片记录独立。
4. **实景观察**：比较普通照片、放大、记录现象、收藏。这里保留原来的证据保存闭环。
5. **专题探究**：柳杉保留完整样板；其余三专题可以切换问题链、写草记和研究计划，明确标为课程草案。计划可导出。
6. **科考档案馆**：收藏 → 三项分析 → 论证板 → 原始来源。
7. **成果交流 / 学习反馈**：作品预览、关联证据、保存草稿与归档、修订记录、附件、导出；回看材料是否齐全并写反思。
8. **课程资料库 / 小天**：搜索分类摘要、记录待读；小天按关键词返回摘要与出处，未匹配时明确说明。
9. **地理组对接清单**：记录意见、材料负责人和预计时间，勾选已讨论项并导出 Markdown，供会后整理。

课程摘要源于《天目山土壤与气候的垂直地带性》《植物地理学野外实习》及对接文件，逐条标注来源位置。摘要与问题链仍需地理组复核，不将文献中的样地值赋给未知采集点的影像。

## 数据与交互边界

- 演示档案存于 `geovoya:demo:v1`。带谱、草记、待读与对接记录使用独立的 `geovoya:` 键。浏览器清理存储后这些记录会消失；可先导出。
- 演示与服务模式的主学习档案独立，演示模式不请求后端；带谱等辅助草记目前都在浏览器本地保存。
- 附件前端演示存储为本地数据，受浏览器配额约束；失败会保留已填写内容并显示错误。服务模式仍由后端保存附件。
- 成果修订和导出保留引用时的证据快照；作品预览反映当前编辑内容，标明未保存状态。
- 过程检查表示已有材料，不是科学结论评分。“已讨论”也不代表资料已提供。
- UI 支持浅色界面、桌面和平板 / 手机重排，导航抽屉、弹窗焦点、键盘环视和排序、减少动态效果。未实现 VR 头显验收。

## 验证命令

```powershell

pnpm test:e2e
```

若使用本机 Chrome 而不是 Playwright 下载的 Chromium，可在运行浏览器测试前设置 `$env:PLAYWRIGHT_CHANNEL = 'chrome'`。前端测试无需后端；服务测试自动启动隔离 API 与 Vite。测试截图、报告、数据库均不入 Git。
